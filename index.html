3D Neuron Anatomical Model

Sculpted from scratch, printed by me, and rendered live!

What it is

Start to finish, this model was made completely by me! I sculpted the neuron from scratch in Nomad Sculpt, remeshed and decimated the mesh by hand, cleaned up in Blender, then sliced and printed it on my own printer (Qidi Tech X-Pro). The model on the left is that same file, the real geometry, rendered live in the browser so you can rotate it, zoom in, and compare it against the photos of the finished print.

Skills it shows

  • 3D Tool Building
  • Voxel remeshing
  • Decimation & topology cleanup
  • Slicing & FDM printing
  • three.js in-browser 3D
  • Fabrication for AAC accessories

Why it's in a speech portfolio

Prepping a mesh so it prints accurately is the same job as making anything that has to fit a real person. Custom AAC accessories (keyguards, switch mounts, tablet brackets, tactile symbols) all run the same pipeline: model it, fix the topology, slice it, print it, then test the fit. This piece is that pipeline end to end, on a subject straight out of my neuroscience coursework.
